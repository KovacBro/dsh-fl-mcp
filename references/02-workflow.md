# 在 FL Studio 里从音符到成品

音符写进钢琴卷帘 ≠ 编曲完成。以下是拿到音符之后的实操路径。

---

## 1. 换音源（FL 脚本 API 不能做，只能手点）

钢琴卷帘里的音符是**通道级**数据，音色由该通道加载的插件决定。

| 声部 | FL 自带可用的 | 说明 |
|---|---|---|
| 钢琴 | FL Keys / DirectWave 钢琴音色包 | FL Keys 轻，做草稿够用 |
| 鼓组 | **FPC**（推荐）或 Sampler 逐个放 | FPC 的打击垫默认映射与 GM 一致，直接认 |
| 电吉他 | FL Slayer / Hardcore | Slayer 自带箱体模拟，适合失真 |
| 木吉他 | DirectWave + 木吉他音色 / FLEX | FLEX 里有免费的 Guitar 预设 |
| 贝斯 | BooBass（快）/ Slayer（脏）/ FLEX | BooBass 只有一个旋钮，草稿友好 |
| 弦乐 | FLEX 的 Strings / DirectWave 弦乐包 | FLEX 免费预设够撑住草稿 |

操作：通道机架 → 右键通道 → Insert / Replace → 选插件。**先换音源再听**，别用默认 Sampler 判断好坏。

## 2. 多声部怎么同时响

三条路，按推荐度排：

**A. 多轨 MIDI 导入（最省事）**
```
fl_export_midi  → 得到 arrange_pop_C_8bar.mid
FL 里：文件 → 导入 → MIDI 文件，或直接把 .mid 拖进播放列表
FL 自动建 6 条轨道 + 6 个 Pattern，每个声部一个
```
缺点：导入后音源是默认的，要按上表换一遍。

**B. 一个 Pattern 一个声部（最可控）**
```
FL 里开 Pattern 2 → 打开它的钢琴卷帘
fl_push_voice(piano) → 写进去
FL 里开 Pattern 3 → fl_push_voice(bass) → …
```
缺点：要手动切 Pattern；优点是每轨独立、可以单独改。

**C. 同 Pattern 叠颜色组**
FL 的钢琴卷帘支持颜色组（脚本的 `color` 字段），一个 Pattern 里可以用不同颜色区分声部。
适合做「同一个乐器的多声部」，不适合做「不同乐器」——因为音色是通道级的。

## 3. 让音符听起来像人弹的

引擎输出的是**量化到 0.25 拍网格**的精确数据，机械感来自这里。FL 里三步救：

1. **人性化**：钢琴卷帘 → 工具 → Humanize（时间 ±5%、力度 ±12）
2. **微调力度**：Ctrl+A 全选 → Alt+拖动（或钢琴卷帘的力度画笔）做渐强
3. **弦乐/铺底加 legato**：工具 → Articulate → Legato，让长音首尾相接

⚠ 别对鼓做过量 humanize，底鼓和贝斯要对齐，散了自己就听出来了。

## 4. 和声标记的用法

`fl_push_voice` 默认会把 `I / V / vi / IV` 写成钢琴卷帘的 marker。

- 时间轴上能看到和声走向，改和声时不用回看报告
- 想关掉：`with_markers=false`

## 5. 常见问题速查

| 现象 | 诊断 | 处理 |
|---|---|---|
| 音符写进去了但没声音 | 通道没加载音源 / 通道静音 / 没路由到 mixer | 通道机架检查音源与静音状态 |
| 音符比我说的位置高一个八度 | FL 的音名比标准高一个八度，MIDI 60 在 FL 里显示 C5 | 正常，不用改 |
| 鼓没声音 | 通道不是 FPC / 采样器没映射 GM 鼓位 | 换 FPC，或把 36/38/42 手动映射 |
| 贝斯和底鼓糊成一团 | 频段冲突 | 贝斯加 high-pass 到 40Hz，kick 侧链压缩 |
| 弦乐像风琴 | 三层音量一样 | 大提琴 -3dB、中提琴 -6dB、小提琴 -2dB |

## 6. 改和声的正确方式

不要直接改音符——改**序进**再重新生成：

1. 告诉 AI：「第 3 小节换成 ii，第 6 小节加个副属 V/V」
2. 重新 `fl_compose`（同 seed 会保持其他声部一致）
3. `fl_push_voice` 重推对应声部（`mode=replace` 会先清空）

同 seed + 改序进 = 其他声部不会乱跳，这是可控迭代的关键。
