# 六声部乐器法与写作规则

引擎里这些规则是代码，不是建议。这里说明**为什么这么写**，以及改的时候要注意什么。

---

## 钢琴 piano · MIDI 36–96

- **左手**：根音 + 五度（36–55），和贝斯错开八度，避免低频打架
- **右手**：3–4 音密集排列（55–84），流行/摇滚/电子的右手用切分（0 / 0.5 / 1.5 / 2.5 / 3.5 拍）
- **排列**：在候选织体池里按「平行进行代价 + 声部移动距离」评分选优，不是固定原位
- **旋律**：取和弦音做骨架，落在 64–86 的高音区，后半月补调内经过音
- 常见错：左右手都弹根音导致低频浑浊；右手排列跨度过大（超过十度会散）

## 鼓组 drums · GM 映射

| 鼓件 | 音高 | 说明 |
|---|---|---|
| kick | 36 | 底鼓，与贝斯根音对齐 |
| snare | 38 | 军鼓，落在 2、4 拍 |
| rim | 37 | 边击，Lo-Fi 用 |
| clap | 39 | 拍手，EDM 用 |
| hat | 42 | 闭合踩镲 |
| ohat | 46 | 开镲，EDM 反拍 |
| crash | 49 | 重音 / 段落开头 |
| ride | 51 | 爵士律动 |
| tom 45/47/50 | | 过门 fill |

- 每 4 小节末拍自动加 fill（snare → tom 下行）
- 常见错：底鼓和贝斯抢同一频段 → 贝斯根音要避开 kick 的瞬态位置

## 电吉他 egtr · MIDI 40–86

- **只用强力和弦**：根音 + 五度 + 八度（`root, root+7, root+12`），不加三音——三音决定大小调，交给钢琴/弦乐
- 节奏型：摇滚八分推进、流行反拍切分、电子十六分短促、爵士 comping
- 闷音感靠**短时值**（0.18–0.44 拍）模拟，不是靠音源
- 常见错：把五度写成减五（根音+6）；跨过 86 会刺耳

## 木吉他 agtr · MIDI 40–84

- **扫弦 strum8**：八分音符，每根弦力度递减 4（模拟下扫的先后与强弱）
- **分解 finger**：低音（根音）与高音交替，八分音符，形成 Travis  picking 的骨架
- 低音永远单独走一路（`root`），和弦音走另一路——这是指弹的基本分工
- 常见错：分解时低音跟着和弦音一起变，听起来像钢琴不像吉他

## 贝斯 bass · MIDI 28–55

- 根音为主；五度做支撑；**最后半拍向下一和弦根音做级进连接**（这是「会走路的贝斯」）
- 律动：`root_whole` / `root_half` / `root5_8th` / `root8_8th` / `octave_8th` / `walking`
- 和底鼓对齐重音，不要和 kick 完全重叠每一个音，留呼吸
- 常见错：贝斯跑到 60 以上，和钢琴左手打架

## 弦乐 strings · MIDI 36–93

三层分工：

| 层 | 乐器 | 音域 | 作用 |
|---|---|---|---|
| 低 | 大提琴 | 36–55 | 根音，撑住低音 |
| 中 | 中提琴 | 53–69 | 内声部，三音/五音 |
| 高 | 小提琴 | 67–90 | 外声部，旋律或高叠 |

**关键实现细节**：先算一条完整的四部（或五部）织体，再按乐器切分。
三层各自独立选音是平行八度的主要来源——因为每一层都在做「就近移动」，
合起来就变成了同向平行。

- `divisi`：时值 0.98 倍，声部之间留缝，适合管弦
- `pad`：1.02 倍，让长音交叠，适合铺底
- `pad_high`：额外叠一层高八度，加亮度

## 平行五/八度的判定口径

引擎的判定（`_parallel_cost`）：

1. 相邻两个和弦，取相同序号的声部对
2. 若两个瞬间的音程都是纯五或纯八
3. 且两声部**同向**移动、位移都不为 0
4. **且这两个音不是同一个和弦音**（同和弦音 = 八度加倍，允许）

→ 满足 1–4 记硬伤（权重 3）；只是同和弦音加倍记 0.2（几乎不影响选优）

这是斯波索宾体系与流行编曲的折中：严格四部写作不许平行八度，
但键盘/管弦写作里「根音上下八度加倍」是常规手法，不该被判死。
